● Antes do código, a explicação do porquê:

  A matriz de correlação é um "mapa de calor" que mede a relação entre cada par de colunas numéricas. O valor vai de -1 a 1:

  - 1 — as duas colunas sobem juntas (correlação perfeita positiva)
  - 0 — não há relação nenhuma
  - -1 — quando uma sobe, a outra desce (correlação perfeita negativa)

  Se duas colunas tiverem correlação de 0.99, estão a dizer a mesma coisa. Dar as duas à IA é redundante e pode prejudicar o modelo. Identificamos essas colunas agora para as podermos eliminar na Fase 3.

  # Calculamos a correlação entre todas as colunas numéricas
  matriz_corr = df_numerico.corr()

  # Criamos uma máscara para esconder o triângulo superior (é espelho do inferior)
  mascara = np.triu(np.ones_like(matriz_corr, dtype=bool))

  fig, ax = plt.subplots(figsize=(18, 14))

  sns.heatmap(
      matriz_corr,
      mask=mascara,
      annot=False,       # não escrevemos os números (há colunas a mais, ficava ilegível)
      cmap="coolwarm",   # azul = correlação negativa, vermelho = correlação positiva
      vmin=-1, vmax=1,
      linewidths=0.3,
      ax=ax
  )

  ax.set_title("Matriz de Correlação — Features Numéricas", fontsize=14, fontweight="bold", pad=15)
  plt.tight_layout()
  plt.show()

  # Identificamos os pares com correlação muito alta (acima de 0.95)
  print("=== Pares com correlação > 0.95 ===")
  for col in matriz_corr.columns:
      for row in matriz_corr.index:
          if row != col:
              valor = matriz_corr.loc[row, col]
              if abs(valor) > 0.95:

Como funciona a mediana para preencher NaN?                                                                                                                                                                               
                                                                                                                                                                                                                               
  Imagina a coluna koi_impact ordenada do menor para o maior valor. A mediana é simplesmente o valor do meio dessa lista.

  Por exemplo, se tivermos: [0.1, 0.3, 0.5, 0.8, 0.9] → a mediana é 0.5

  Cada buraco (NaN) nessa coluna foi substituído por esse valor do meio. Fizemos isto coluna a coluna — cada coluna tem a sua própria mediana.

  Usámos mediana em vez de média porque se houver valores extremos (como aquele período orbital de 129.995 dias), a média fica "puxada" para cima e deixa de representar o valor típico. A mediana não se deixa enganar por    
  isso.

  ---
  2. Como o MinMaxScaler transforma para [0, 1]?

  A fórmula matemática é esta:

  valor_novo = (valor - mínimo) / (máximo - mínimo)

  Exemplo com koi_period:
  - Mínimo = 0.24 dias, Máximo = 129.995 dias
  - Um planeta com período de 65.000 dias ficaria: (65000 - 0.24) / (129995 - 0.24) = 0.50
  - O planeta com o período mínimo fica sempre 0
  - O planeta com o período máximo fica sempre 1

  O fit_transform() que usámos faz exactamente isto — primeiro aprende o mínimo e máximo de cada coluna (fit), depois aplica a fórmula a todos os valores (transform).

❯ sim ficou claro, aformula retirou o valor real e tirou o minimo da respetiva coluna e dividiu pela variancia para se apresentar entre o e 1 pois a variancia sempre sera maior ou igual que o numerador                                                                                                                                                                                                                      
● Quase perfeito! Só uma correção técnica importante:                                                                                                                                                                          
  
  O que dividiste não é a variância — é o intervalo (ou amplitude), que é máximo - mínimo.                                                                                                                                                                                                                                                                                                                                                                    
  A variância é um conceito diferente — mede o quanto os valores se afastam da média. Não é isso que usámos aqui.                                                                                                              
  
  O que usámos foi:

  (valor - mínimo) / (máximo - mínimo)

  O denominador máximo - mínimo é sempre maior ou igual ao numerador valor - mínimo — tens razão nessa parte! Por isso o resultado fica sempre entre 0 e 1.
